## Adding a maintainer

We add a new maintainer when a contributor has:

1. Landed at least **5 non-trivial PRs** to this package.
2. Demonstrated familiarity with the A2A v0.3 spec, ADK, and Cloud Run
   deployment.
3. Agreed in writing to the security-disclosure SLA in
   [SECURITY.md §2](./SECURITY.md).

Nominations are proposed in a public GitHub issue and approved by a
**unanimous vote** of existing maintainers (currently 1 — so any new
maintainer requires Kim Sejun's explicit approval).
