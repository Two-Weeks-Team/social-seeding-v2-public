## Long description (Markdown, ~700 words)

```markdown
# Influencer Research Agent (TikTok)

**One-paragraph version:** turn a one-paragraph brand brief into a ranked
top-10 of TikTok creators in roughly fifteen seconds. Built on Google ADK,
deployed to Cloud Run, listable in Gemini Enterprise via both the A2A skill
surface (`plan_creator_search`) and the underlying MCP tool surface (4
read-only TikTok tools). Free tier preserves a 200/200/50/50 daily quota
per user; Pro tier extends it 10× at $49/month.

## What it does

Given a one- or two-paragraph brand brief — for example *"We're launching
a vegan skincare line in Korea targeting Gen-Z women aged 18-26"* — the
agent:

1. **Plans** keyword variants across language and audience axes. Korean,
   English, and Japanese variants run in parallel.
2. **Sources** candidate creators via `tiktok_search`, dedupes by handle,
   filters anything below the 5K-follower spam threshold.
3. **Enriches** the top 30 with `tiktok_user_info` so the ranker has bio
   context — not just follower counts.
4. **Ranks** the survivors using `tiktok_user_posts` + `tiktok_post_detail`
   to compute engagement rate and a Gemini-2.5-Pro brief-fit score.
5. **Explains** every choice in two sentences so the brand operator can
   sanity-check the ranking before committing budget.

## Who it's for

* B2C and DTC brands launching campaigns in Asia (esp. KR + JP)
* Influencer-marketing agencies that need a faster shortlist pipeline
* Marketing analytics teams already on Gemini Enterprise

## Why it's an agent, not a tool

The four `tiktok_*` MCP tools are listed separately in the MCP connector
catalogue (Path B, REFACTOR-MCP §2.3). This listing is the **agent** built
on top of those tools — it owns the orchestration, the LLM-driven planning,
and the structured output schema (`RankedCreators`). An enterprise customer
gets a single skill call instead of having to chain four tool invocations
themselves.

## Architecture

The whole agent ships as a single Cloud Run service (multi-container):

* **Container A — `mcp-adk`**: Python 3.13 + FastAPI + Google ADK. Primary
  ingress on port 8200. Verifies Identity Platform ID tokens on every
  request; wraps Gemini calls with Model Armor (`FAIL_CLOSED`).
* **Container B — `mcp-node`**: Node 22 + TypeScript. The existing
  tiktok-mcp-server, talking to Social Seeding's production TikTok
  pipeline at `backend.socialseed.ing`. Loopback-only on port 8100.

The two containers share a pod-local network; the ADK agent never crosses
a Cloud Run service boundary to call its MCP tools, so cold-start latency
is bounded and there's no cross-service auth overhead.

## Compliance and security

* **OAuth 2.1 / OIDC** via Identity Platform (multi-tenant; per-customer
  tenant on demand). Replaces a SQLite-backed OAuth server that did not
  survive Cloud Run autoscaling.
* **Model Armor** with the max-tier policy (D21): prompt injection +
  jailbreak at MEDIUM_AND_ABOVE, RAI default filters, custom regex for
  GCP API keys / AWS access keys / private-key blocks / influencer IDs.
  `FAIL_CLOSED` — any MA error blocks the call, never silently passes.
* **Audit logging** to Cloud Logging on every model and tool call;
  trace_id propagated end-to-end so per-request lineage reconstructs
  cleanly from BigQuery.
* **No long-lived secrets** in container — Secret Manager binding on
  every credential the runtime needs (Identity Platform tenant id,
  backend dashboard credentials, Sentry DSN).
* **CVE scanning** on every Cloud Build pipeline (`gcloud artifacts
  docker images scan`); HIGH/CRITICAL findings block deploy.

## Limitations to know about

* **TikTok data is public-data only.** No TikTok Research API. Scraping
  rides on the existing RapidAPI-mediated path (D8/D14).
* **English-language listing.** Korean/JP/CN briefs are accepted; the
  listing copy is English-only because Marketplace reviewers default to
  English (REFACTOR-MCP §9.3).
* **Per-user quota uses Firestore.** Free-tier numbers above are per
  Identity Platform `uid`, not per workspace. A workspace with 10 active
  users gets 10× the quota — by design.
```
