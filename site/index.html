Social Seeding v2
Agent-Orchestrated TikTok Campaign Operator

The agent is the operator. A 22-agent ADK fleet sources, vets, contacts, ships, and verifies — humans approve only the gates that matter. Built on Vertex AI Agent Runtime, Spanner, AlloyDB, and Cloud Workflows. Dual submission: Track 2 (Optimize) + Track 3 (Refactor).

▶ LIVE INTERACTIVE DEMO 📊 Progress Report (2026-05-19) 🔗 GitHub Repo
What this is — Social Seeding v2 is the Track-2 entry for the Google for Startups AI Agents Challenge 2026: a multi-tenant, multi-region SaaS that runs influencer-marketing campaigns end-to-end with a fleet of typed, capped, escalation-aware agents. Its sibling Track-3 entry, tiktok-mcp-server, packages the same TikTok scrapers as an A2A v0.3 agent registered with Gemini Enterprise — turning the Korean-Marketplace listing gap (per D2) into an innovation talking-point (per D3, D29-B). The demo on this page reproduces 24 mouse-driven scenes from both submissions, with subtitles in 4 locales (per D34).

Click the big blue button above for the 6-minute walkthrough. No signup, no GCP project, runs entirely in your browser.
D29 · Three differentiation angles

All three angles, not one

Per Decision D29, the submission claims three independent differentiators — and the demo emphasizes whichever angle the active scene illustrates. The 24 scene cards below each carry an angle badge (A/B/C/ALL).

D29-A · Agent-as-function

Typed, capped, escalation-aware

22 production agents · 49 capability tools · Pydantic input/output contracts · per-call USD cap · automatic escalation gate · judge-as-tool — far beyond a free-running ReAct loop. Every agent has a golden-set eval before the phase that depends on it is "done".

D29-B · KR region-gap → A2A innovation

The listing gap, reframed

Korean legal entities cannot list paid agents on Google Marketplace (D2 payment-region exclusion). The Track-3 entry reframes that as an A2A-only distribution path — a v0.3-compliant agent.json, Gemini Enterprise discovery, OIDC-gated Cloud Run, distribution without Marketplace billing.

D29-C · Multimodal + AP2 + Multi-agent

Veo + Imagen + Lyria, AP2, RemoteA2AAgent

Multimodal creative generation (Veo video, Imagen stills, Lyria audio) · AP2 Intent Mandate per D27 (Cart/Payment Mandate read-only) · RemoteA2AAgent fleet coordination · Model Armor on every model call · Chronicle SIEM for the audit chain.

Stack

Built on the GCP Agent Platform

Vertex AI Agent Runtime hosts the ADK 2.0 Beta fleet. Spanner + AlloyDB AI + Firestore form the data plane. Cloud Workflows + Pub/Sub + Cloud Tasks + Eventarc are the durable orchestrator (Inngest retired per D18). Identity Platform multi-tenant + Model Armor + Chronicle SIEM cover the safety stack.

D1 · Dual submission

Two entries, one platform

Track 2 takes the existing v2 codebase to the GCP Agent Platform. Track 3 wraps the TikTok scraper as a discoverable A2A agent — and turns the Korean-Marketplace listing gap into the contribution narrative.
