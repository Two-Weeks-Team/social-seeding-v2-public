# `scripts/demo/assets/outro/` — Per-track 5-second outro CTA cards

> **Purpose**: the 5-second closing card that follows Beat 6 in each demo. Carries the GitHub repo URL, the deployed-service URL, and the license — exactly the three pieces of text [`SUBMISSION-PACKAGE.md`](../../../../gcp-research/demo-deliverables/SUBMISSION-PACKAGE.md) §1 calls out as "Judges screenshot this."
