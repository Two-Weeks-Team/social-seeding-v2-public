# `scripts/demo/assets/intro/` — Per-track 5-second intro cards

> **Purpose**: a 5-second opening card that precedes the live agent run in each demo video. Bridges the "hard 0:00 cut" the operator hates and gives the viewer a moment to read the project name + track before the 8× speed kicks in.

## Files

| File                    | Track       | Dimensions | Generated by                          |
|-------------------------|-------------|------------|---------------------------------------|
| `track2-intro-card.png` | v2          | 1920×1080  | `bash render-intro-cards.sh` (below)  |
| `track3-intro-card.png` | mcp         | 1920×1080  | same                                  |

The PNGs are **NOT committed** as binaries — the repo carries only this README + the generator. Regenerate locally any time you re-style.

## Rendering

```bash
bash scripts/demo/assets/intro/render-intro-cards.sh
```

Renders both PNGs using ImageMagick. Requires `magick` (ImageMagick 7.x). The output lands beside this README. The post-process chain ([`scripts/demo/post-process/overlay-burn.sh`](../../post-process/overlay-burn.sh)) optionally consumes these cards if they exist; if not, the chain still produces a valid 3:00 cut without the intro card.
