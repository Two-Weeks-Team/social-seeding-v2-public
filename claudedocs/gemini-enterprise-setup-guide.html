우리 에이전트는 이미 A2A v0.3 카드 + JWKS로 동작 중입니다. 남은 건 그걸 Gemini Enterprise 앱에 등록해서 Agent Gallery에서 발견·호출되게 하는 것.

전체 체인: Gemini Enterprise 구독(무료체험) → 앱 생성 → (Claude가) A2A 에이전트 등록

앞의 두 단계가 당신 몫(계정/구독), 마지막이 Claude 몫입니다.

🟢 이미 끝난 것 완료

  • discoveryengine.googleapis.com 활성화 (ss-mcp-prod) — A2A 등록 REST의 백엔드
  • modelarmor · agentregistry · observability API 활성화
  • 라이브 A2A 카드 동작 확인: …run.app/.well-known/agent.json → 200
⚠️ 등록 전 Claude가 먼저 고칠 것: 카드가 광고하는 mcp.socialseed.ing가 현재 404입니다. 등록 시엔 동작하는 run.app 엔드포인트를 쓰도록 Claude가 맞춰서 등록합니다(당신은 신경 안 써도 됨).

③ A2A 에이전트 등록 🔵 Claude가

앱이 생기면 Claude가 둘 중 하나로 등록합니다 — 당신은 안 해도 됩니다.

  • 콘솔: Gemini Enterprise → 앱 선택 → Agents > Add Agents → Custom agent via A2A → 동작하는 카드 JSON 붙여넣기 → Preview > Next → Skip & Finish
  • 또는 REST: POST …/v1alpha/projects/ss-mcp-prod/locations/global/collections/default_collection/engines/<APP_ID>/assistants/default_assistant/agents
보안 보너스: A2A 에이전트는 Model Armor를 에이전트 코드 안에서 REST로 설정해야 보호됩니다(콘솔 설정은 A2A에 자동 적용 안 됨). 우리는 코드에 model_armor_query_blocks가 이미 있어 충족 — Claude가 라이브로 켭니다.

🧰 막히면: 조직(Organization) 먼저 만들기 🟠 당신

①에서 “조직/도메인이 필요하다”고 나올 때만. 현재 계정은 소비자 Gmail이라 조직이 없습니다. 당신이 소유한 socialseed.ing 도메인으로 무료 조직을 만들 수 있습니다.

1
Cloud Identity Free 가입 — 도메인 socialseed.ing 사용
Cloud Identity Free 가입 ↗
도메인 등록기관(DNS) 관리자 접근이 필요합니다. 무료 50 사용자.
2
도메인 소유 확인(DNS TXT) — 가입 마법사가 주는 TXT 레코드를 socialseed.ing DNS에 추가. 확인되면 GCP 조직 노드가 자동 생성됩니다.
3
①로 돌아가 다시 시도 — 이제 조직이 있으니 Gemini Enterprise 구독이 통과됩니다.
절대 하지 말 것(심사 기간): 라이브 ss-mcp-prod 프로젝트를 새 조직으로 이전(migrate)하지 마세요 — 데모 URL/IAM이 깨질 수 있습니다. 조직이 필요하면 조직 산하에 새 프로젝트를 만들어 거기서 진행(Claude가 재배포/등록)하거나, 이전은 제출 후로 미루세요.

⏱️ 현실 체크 (정직)

  • 심사엔 필수 아님: 우리 A2A 카드 + JWKS만으로 에이전트는 이미 발견·호출 가능. Gemini Enterprise 등록은 가점/업그레이드입니다.
  • 막힐 수 있는 지점: ① 구독이 조직을 요구할 가능성, 또는 구 geminienterprise.googleapis.com API의 allowlist(과거 220002). 조직 + DNS 검증은 며칠~1·2주 걸릴 수 있어 지금 시작하는 게 맞습니다.
