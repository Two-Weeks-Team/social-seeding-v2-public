3. 팀원 런북 — 직접 실행

A. GCP 루프 1회 실행 (source→vet, 실데이터)

args.json 작성 (campaignId + agent_urls + brief). agent_urls에 coordinator/sourcing/vetting(ss-agents) + tiktok-mcp-search(ss-mcp) URL 포함.
실행: 
gcloud workflows run brand-campaign-demo \
  --project ss-v2-prod --location us-central1 \
  --data="$(cat args.json)"
결과 확인: state=SUCCEEDED, rankedCreators[](fit_score + reasoning). 콘솔: Cloud Workflows → brand-campaign-demo → Executions.

B. authed vetting E2E (직접 호출)

런타임 SA OIDC 토큰 발급: 
TOKEN=$(gcloud auth print-identity-token \
  --impersonate-service-account=ss-agents-runtime@ss-v2-prod.iam.gserviceaccount.com \
  --audiences=https://ss-agents-p7qelej4vq-uc.a.run.app)
POST /vetting with VettingInput(brief + candidate.creator.uniqueId). → kind=ok + 실 TikTok 수치 + Gemini 랭킹.

C. Gmail 연결 (재사용 — 모든 사용자 동일)

브라우저에서 https://agents.socialseed.ing/api/auth/gmail/start?email=<계정> 열기 → Google 동의(gmail.send) 승인.
콜백이 refresh token을 공유 백엔드 user_tokens에 저장(자동). 페이지가 ?gmail_connected=<email>로 복귀.
이후 ADK gmail_send_reply(live)가 그 토큰으로 Gmail API 발송. D10 allow-list 내 계정만.
